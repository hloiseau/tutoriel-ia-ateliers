Nous avons vu comment manipuler les marque-pages et comment les utiliser pour manipuler du contenu.  
Les marque-pages permettent de faire aussi beaucoup d'autres choses. La documentation complète sur les marque-pages est disponible avec la commande `:h mark-motions`.

[[attention | On sait maintenant:]]
| - Crée un marque-page (avec `m` ou `:mark`)
| - Afficher ses marque-pages avec `:marks`
| - Se déplacer à un marque page (avec `` ` `` ou `'`, suivis de son nom)
| - Les marque-pages *sont* des mouvements
| - Supprimer des marque-pages avec la commande `:delm`
