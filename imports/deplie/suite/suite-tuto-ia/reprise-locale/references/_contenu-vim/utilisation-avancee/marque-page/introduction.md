Lorsque vous travaillez avec beaucoup de fichiers (ou des fichiers très longs) il peut être utile de rapidement sauter d'un endroit à l'autre.  
Pour cela on va utiliser des *marks*.

Il existe deux types de marque-pages :
1. Les marque-pages temporaires (Ils sont présents tant que le *buffer* est ouvert)
2. Les marque-pages persistants (Ils sont présents jusqu'à ce qu'on les supprime)

[[information]]
| La documentation est accessible avec la commande `:help mark`.
