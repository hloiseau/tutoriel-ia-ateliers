Nous avons vu précédemment comment installer des plugins.  
Dans cette partie je vais vous partager des plugins que j'utilise.

1. [NERDTree](https://github.com/preservim/nerdtree)  
  Ce plugin remplace l'explorateur de fichier présent initialement dans Vim. Je le trouve un peu plus joli, mais aussi plus pratique à utiliser. Il met à disposition des raccourcis pour créer, renommer, supprimer, ... les fichiers et répertoires.

2. [YouCompleteMe](https://github.com/ycm-core/YouCompleteMe)  
  Ici c'est un outil qui permet l'auto-complétion.

6. [vim-fugitive](https://github.com/tpope/vim-fugitive)  
  Un plugin vim pour git, ou un plugin git pour vim.  ;) 

5. [ALE](https://github.com/dense-analysis/ale)  
  Un linter qui permet de vérifier la syntaxe et les erreurs sémantiques.

3. [vim-go](https://github.com/fatih/vim-go)  
  Une extension pour Go implémenté par-dessus un LSP qui apporte toutes les fonctionnalités des plus grands IDE (même un débugger facile à utiliser).

4. [black](https://black.readthedocs.io/en/stable/integrations/editors.html#vim)  
  Le plugin Vim de [Black](https://black.readthedocs.io/en/stable/index.html), *«The uncompromising code formatter»* pour python.


*[ALE]: Asynchronous Lint Engine
