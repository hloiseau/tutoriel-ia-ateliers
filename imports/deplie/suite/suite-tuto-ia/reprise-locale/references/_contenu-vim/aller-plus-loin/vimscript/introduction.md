Il existe de multiples plugins pour divers usages. Cependant vous n'êtes pas à l'abri d'avoir un usage si particulier que le plugin que vous cherchez n'existe pas encore. Pour cela, il vous suffit *juste* de l'écrire vous-même.

Pour développer des extensions, Vim utilise son propre langage: [Vimscript](https://en.wikipedia.org/wiki/Vim_(text_editor)#Vim_script) ou VimL.

Le sujet d'écriture d'un plugin et de l'apprentissage de Vimscript pourrait être un tutoriel complet à lui-même. C'est pourquoi nous n'allons pas couvrir ce sujet ici. Voici des ressources qui peuvent vous orienter si le sujet vous intéresse:

- Pour une introduction aux types de données, les structures conditionnelles, les boucles et les fonctions: https://learnvim.irian.to/vimscript/vimscript_basic_data_types
- Une documentation Vim pour apprendre le langage: https://github.com/dahu/LearnVimL
- Une liste récapitulative: https://learnxinyminutes.com/vimscript/
