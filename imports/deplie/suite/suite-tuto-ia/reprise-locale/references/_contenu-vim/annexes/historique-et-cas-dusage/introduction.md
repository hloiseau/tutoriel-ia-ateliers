Vim est un éditeur de fichier créé par [Bram Moolenaar](https://fr.wikipedia.org/wiki/Bram_Moolenaar "Page Wikipedia de Bram Moolenaar"). Il avait pour but d'imiter le comportement de [vi](https://fr.wikipedia.org/wiki/Vi "Page Wikipedia de vi") sur son ordinateur (qui était dépourvu de vi). Le projet commence en 1991.

[[information]]
| Vim est open source, vous pouvez consulter son code source [à cette adresse](https://github.com/vim/vim "Github de Vim").

À cette époque, en 1991, les interfaces graphiques n'étaient pas répandues partout. Les ordinateurs s'utilisaient au travers de terminaux (utilisable sans souris). De ce fait, une partie des logiciels développés (dont Vim) sur les ordinateurs de l'époque sont utilisables uniquement au clavier.

Au départ Vim (Vi IMitation) était une imitation de vi. Aujourd'hui il est une version améliorée (Vi IMproved) qui a presque totalement remplacé vi.

Aujourd'hui [Neovim](https://fr.wikipedia.org/wiki/Neovim "Page Wikipedia de Neovim") est à Vim ce qu'en 1991 Vim était à vi. Neovim se veut entièrement compatible avec Vim tout en proposant une meilleure intégration dans les outils modernes, notamment les interfaces graphiques.

Vim est conçue pour fonctionner dans un terminal et uniquement au clavier. C'est pourquoi si la vue d'un terminal vous effraye ce n'est peut-être pas un outil adapté pour vous. On peut mentionner que vim est utilisable au travers d'une interface graphique nommée *GVim*.
Vim est aussi conçu pour fonctionner lorsqu'on se connecter sur un ordinateur à distance, héritage de vi. Par exemple, il est possible que le logiciel de connexion à distance ne permette pas d'utiliser [les touches directionnelles](https://fr.wikipedia.org/wiki/Touches_directionnelles "Page wikipedia des touches directionnelles") pour déplacer le curseur, néanmoins on peut le déplacer avec les touches `h`, `j`, `k` et `l`.
