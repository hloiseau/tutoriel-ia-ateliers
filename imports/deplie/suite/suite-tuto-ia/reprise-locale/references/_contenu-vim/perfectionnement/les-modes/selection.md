Le mode sélection fonctionne comme la sélection des logiciels traitements de texte classique (MS Office, Libre office, ...). C'est-à-dire qu'en mode sélection le premier caractère tapé remplace le texte qui a été sélectionné et insère les caractères suivants.

Pour passer en mode sélection il faut dans un premier temps être en mode visuel avec du texte sélectionné. Lorsque le texte choisi est surligné, le passage en mode sélection se fait avec `Ctrl + g`.

Pour retourner en mode normal, il faut appuyer sur la touche `Esc`.
