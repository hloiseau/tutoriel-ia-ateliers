Le mode remplacement est très similaire au mode insertion. Là où le mode insertion ajoute des caractères, le mode remplacement *remplace* le caractère sous le curseur par celui tapé.

Le mode insertion et remplacement existe depuis des années sur les ordinateurs ([Page Wikipédia de la touche insertion](https://fr.wikipedia.org/wiki/Touche_d%27insertion "Page Wikipédia de la touche insertion")).

Pour entrer en mode remplacement dans Vim, on utilise la commande `R` (`Maj + r`), pour quitter ce mode, il suffit simplement de presser la touche `Esc`.
