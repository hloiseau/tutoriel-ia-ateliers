Le fording est un mécanisme qui permet de *plier* un fichier à fin de cacher du code.  
C'est une fonction qui existe dans quasiment tous les éditeurs de fichier et IDE.

Voici un exemple:

->![](/media/galleries/11359/e83d1964-1245-4b33-8d8c-52797b2c1d99.png)<-

->![](/media/galleries/11359/ef46ac03-b372-43f1-86da-d18ff3d9103e.png)<-

Ici, nous avons plié la fonction `init`.

En cachant une partie du ficher dont nous n'avons pas besoin pour le moment, nous pouvons naviguer plus rapidement dans la longueur du fichier. Cependant, une utilisation excessive peut entrainer des fichiers trop longs (ce qui n'est pas optimal notamment pour du code).
