Vim est un éditeur **modal**. C'est sa principale différence avec les autres éditeurs.

Les modes permettent d'effectuer différentes tâches. C'est ce fonctionnement modal qui pose souvent problème aux débutants.

Nous avons rapidement parlé des modes dans la partie précédente. Ici, nous allons consacrer le chapitre aux principaux modes de vim.
