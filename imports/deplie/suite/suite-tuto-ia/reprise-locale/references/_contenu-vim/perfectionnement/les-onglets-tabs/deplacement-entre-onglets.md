Voici les commandes de navigation pour les onglets:

| Commande | Explication |
|:--------:|:------------|
| `gt` | Passer à l'onglet suivant |
| `gT` | Passer à l'onglet précédent |
| `<nb>gt` | Passer à l'onglet `<nb>` |
| `:tabclose` | Fermer un onglet |
| `:tabmove <nb>` | Déplace l'onglet en position `<nb>`, si `<nb>` est absent l'onglet sera mis en dernier |

[[information]]
| Lorsque toutes les fenêtres d'un onglet sont fermées, l'onglet se ferme lui aussi automatiquement.

Il vous arrivera peut-être d'avoir un jour un grand nombre de fenêtres ouvertes. Sachez qu'il est possible de convertir une fenêtre en onglet avec la commande `Ctrl` + `w` puis `T`.
