Ces registres sont en lecture seule, c'est-à-dire que nous ne pouvons pas écrire dedans.

Le registre `":` contient la dernière commande faite en mode Ligne de commande.

Le registre `".` contient le dernier texte ajouté en mode Insertion.

Le registre `"%` contient le nom du fichier courant.

Le registre `"#` contient le nom du dernier fichier visité.

Comme vous pouvez vous en douter, ces registres changent régulièrement de valeurs.
