Le mode normal de Vim est celui qui est actif lors de son ouverture.

Ce mode est destiné à l'exécution de commandes.  
Nous avons déjà vu certaines commandes, telles que `dd` pour couper la ligne sur laquelle est le curseur.

Les commandes sont très utiles et puissantes, c'est pourquoi le chapitre suivant leur est dédié.
