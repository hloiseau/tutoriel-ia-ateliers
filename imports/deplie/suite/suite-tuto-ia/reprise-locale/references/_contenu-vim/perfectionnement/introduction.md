Dans cette partie nous allons apprendre les mécaniques de Vim qui permettent d'utiliser l'outil de manière efficace.

Je mentionnerai l'aide de Vim. C'est la documentation des fonctionnalités du logiciel.  Pour y accéder, on utilise la commande `:help` ou `:h`. Cela ouvre un viewport sur l'aide.  
Je vous invite à lire le début de l'aide qui vous apprendra notamment comment naviguer dans l'aide.  
Si vous avez besoin d'informations à propos d'une commande ou d'un élément concernant Vim, c'est dans cet endroit que vous le trouverez. Par exemple si vous voulez plus d'informations sur les windows, entrez la commande `:h window`. Vous y trouverez des informations bien plus approfondies que vous ne pourriez trouver ici.
