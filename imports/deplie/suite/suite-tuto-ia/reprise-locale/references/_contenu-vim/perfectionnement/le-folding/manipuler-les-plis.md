Pour ouvrir un pli, on utilise la commande `zo` (`o` pour open). Pour le refermer on utilise la commande `zc` (`c` comme close).  
On peut aussi ouvrir et fermer un pli avec `za`. Ceci va ouvrir le pli fermé et fermer le pli ouvert.

Ces commandes ferment le pli courant. On peut néanmoins manipuler tous les plis jusqu'au plus haut de la hiérarchie avec les commandes `zO`, `zC` et `zA`.

Il est aussi possible de manipuler **tous** les plis du fichier.

On utilisera les commandes `zM` pour fermer tous les plis et `zR` pour l'opération inverse.  
On peut aussi fermer le pli le plus profond dans la hiérarchie (qui n'est pas déjà fermée) avec la commande `zm`. De la même manière, on peut ouvrir les plus grands plis de la hiérarchie avec la commande `zr`.
