La page de [téléchargement de Vim](https://www.vim.org/download.php "Page de téléchargement de Vim") nous indique que nous devons nous intéresser au projet [MacVim](https://github.com/macvim-dev/macvim "GitHub du projet MacVim").

MacVim peut s'installer par [Homebrew](https://fr.wikipedia.org/wiki/Homebrew_(gestionnaire_de_paquets) "Page Wikipedia de Homebrew") ou bien par [MacPorts](https://fr.wikipedia.org/wiki/MacPorts "Page Wikipadia de MacPorts").

Ouvrez un terminal et tapez:
```console
brew install vim
```
Si vous voulez installer Vim depuis Homebrew ou:
```console
port install vim
```
Si vous voulez installer Vim depuis MacPorts.
