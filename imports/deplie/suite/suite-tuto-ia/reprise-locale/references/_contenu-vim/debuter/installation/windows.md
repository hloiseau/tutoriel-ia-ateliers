Pour installer Vim sous Windows nous allons télécharger l'installeur sur [la page de téléchargement du site officiel de Vim](https://www.vim.org/download.php "Page de téléchargement de Vim").

Nous allons choisir "self-installing executable", comme le montre l'image suivante

->
![](/media/galleries/11359/8ee897aa-4808-40f6-917d-e2e8a77e6498.png)
<-

Windows va donc télécharger l'installeur dans vos fichiers.  
Lorsque le téléchargement est fini, double-cliquez sur l'exécutable.

[[information]]
| Windows vous demandera peut-être les droits administrateur pour installer le logiciel.

->
![](/media/galleries/11359/f9fef51a-1e75-454f-82e9-4fe2ee0d55bb.png)
<-

À présent, Vim vous demande de sélectionner votre langue, je choisis "English", cependant vous pouvez choisir celle qui vous convient.

->
![](/media/galleries/11359/40b43e6e-1c32-4634-b86a-76a753f2ae32.png)
<-

On clique sur `Next >`.

->
![](/media/galleries/11359/6063e2aa-00b2-465c-929b-b9e5ba339fc3.png)
<-

Si vous voulez installer Vim, vous devez accepter le contrat de licence et cliquer sur `Next >`.

->
![](/media/galleries/11359/2c669ffa-ffeb-40ed-8b55-ac6a1e0a6b85.png)
<-

L'installeur Vim nous laisse choisir les composants de Vim nous souhaitons installer. Je fais le choix de tout installer.  
On clique sur `Next >`.

->
![](/media/galleries/11359/96b4e80d-ae34-41db-bae2-4e125f1ef834.png)
<-

Maintenant, on nous demande nos choix de configuration, je vous conseille de tout laisser aux valeurs par défaut.

->
![](/media/galleries/11359/1aa64a01-ff68-43ee-acaa-ce8013006210.png)
<-

Ensuite, on nous demande où nous souhaitons installer Vim. Ici aussi je vous conseille de laisser la valeur par défaut.  
On clique sur `Install` pour démarrer l'installation.

->
![](/media/galleries/11359/1a8ca0c6-4058-47aa-b046-6b56bd78facf.png)
<-

Vim s'installe.

->
![](/media/galleries/11359/fca40763-3e37-4549-8346-12d48f7edb3f.png)
<-

Vim nous dit qu'il s'est installé, on clique sur `Finish`.
