Sous BSD, nous allons installer Vim en utilisant le gestionnaire de paquets.

Pour cela nous allons ouvrir un terminal et taper la commande correspondant à notre gestionnaire de paquets.

[[information]]
| Vous pouvez aussi l’installer via un gestionnaire de paquets graphique.

Exemples:

- `pkg install vim` pour [FreeBSD](https://fr.wikipedia.org/wiki/FreeBSD "Page Wikipedia de FreeBSD")
- `pkg_add vim` pour [OpenBSD](https://fr.wikipedia.org/wiki/OpenBSD "Page Wikipedia d'OpenBSD")
- ...
