Les packages ressemblent beaucoup aux plugins. Ces derniers peuvent contenir un ou plusieurs plugins.  
Regrouper les plugins sous forme de package permet de le télécharger sous forme d'une archive et de l'extraire dans son répertoire sans le mélanger aux autres plugins et packages. Aussi de faciliter les mises à jour de ces derniers (si par exemple le package provient d'un dépôt git).

[[information]]
| La documentation complète sur les packages peut être obtenue avec la commande `:h package`.
