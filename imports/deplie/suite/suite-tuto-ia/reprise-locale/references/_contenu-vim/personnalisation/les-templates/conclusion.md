L'expression `*.html` dans la ligne `autocmd BufNewFile *.html 0r ~/tpl.html` du `.vimrc` peut-être plus complexe afin d'utiliser un template plus spécifique en fonction du nom du fichier crée (par exemple pour vos fichiers de tests, si vous êtes un développeur).

[[information]]
| Toute l'aide sur les templates peut-être obtenue avec la commande `:h template`.

[[attention | On sait maintenant:]]
| - Ouvrir un fichier avec un modèle précis selon le type de fichier ouvert
