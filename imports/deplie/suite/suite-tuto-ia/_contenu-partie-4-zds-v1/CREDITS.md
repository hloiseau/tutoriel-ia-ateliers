# Crédits et sources

Les illustrations ont été créées pour ce tutoriel. Les résultats de tests proviennent des scripts fournis. Le graphique de volume des paramètres est un calcul théorique explicitement identifié ; il ne représente pas une mesure de RAM ou de mémoire vidéo.

Les modèles externes et leurs fichiers ne sont pas redistribués dans cette archive. Leur provenance est donnée dans les notes et, pour l’atelier local, dans `modele.json`.

La forme suit [Rédiger sur ZdS](https://zestedesavoir.com/tutoriels/249/rediger-sur-zds/). Le tutoriel [Vim](https://zestedesavoir.com/tutoriels/3575/vim/) sert de référence pour une progression pratique et un ton accessible, sans reproduction de son texte.

Les sources techniques figurent dans les notes des sections concernées.
