# Une histoire de l’IA — version complète à relire

Cette archive contient la partie historique du futur tutoriel, présentée seule pour pouvoir la relire dans ZdS : sept chapitres, avec leurs introductions, sections et conclusions.

## Importer dans ZdS

1. Créez un contenu de travail pour cette partie, puis ouvrez son formulaire d’import.
2. Dans le champ de l’archive de contenu, sélectionnez `histoire-ia-zds.zip`.
3. Dans le champ de l’archive d’images, sélectionnez **le même fichier**.
4. Après l’import, ouvrez la prévisualisation et vérifiez les images et les notes.

Le fichier `manifest.json` est à la racine. Les liens `image:images/…` sont destinés au remplacement automatique par les adresses de la galerie ZdS lors de l’import des images. La structure et les chemins ont été vérifiés à partir de l’export fourni et du code public de l’importeur ; l’import sur votre compte n’a pas été testé.

## Relire ou modifier

- `relecture.html` : lecture continue avec sommaire, notes et images intégrées. Ouvrez ce fichier dans un navigateur, même sans connexion. Son rendu est un aperçu de lecture, pas une reproduction exacte du rendu ZdS.
- `relecture.md` : la même lecture en Markdown, avec des images locales.
- `sommaire.md` : le détail des sept chapitres.
- `01-origines/` à `07-aujourdhui/` : les fichiers à modifier, une section par fichier.
- `images/` : deux photographies historiques et dix schémas pédagogiques.
- `sources.json` : les références utilisées pour les notes.
- `CREDITS.md` : les crédits des illustrations et la référence du guide de rédaction.

Le manifeste utilise les petits fichiers des chapitres. Les versions de lecture continue sont des copies assemblées : les modifier ne change pas les fichiers importés.

Les chapitres sont marqués comme non prêts à publier dans le manifeste, afin de garder cette version comme un texte de travail à relire.
