# Archives sources

Les trois archives déposées par l’auteur ont été intégrées dans les quatre premières parties du [tutoriel](../../../SOMMAIRE.md).

| Archive conservée | Sources courantes |
| --- | --- |
| `histoire-ia-zds-v3.zip` | `tutoriel/01-histoire/` |
| `apprentissage-ia-zds-v2.zip` | `tutoriel/02-apprentissage/` |
| `tutoriel-ia-suite-parties-3-4.zip` | `tutoriel/03-modele-local/` et `tutoriel/04-developpement/` |

Les ZIP servent de provenance ; ne pas les modifier pour corriger le tutoriel. Modifier les sources courantes et régénérer les exports avec `outils/assembler_tutoriel.py`.

`provenance.json` conserve les empreintes des archives et des fichiers récupérés avant les raccords éditoriaux. Les documents et scripts historiques non repris comme fichiers courants restent consultables dans ces archives.
