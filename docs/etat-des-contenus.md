## Intégration du 20 septembre

La branche de travail `parcours-dev-travail-2026-09-18` et les cinq ZIP de parties sauvegardés le 18 septembre constituent les sources de cette intégration. Les ateliers restaurés restent dans leurs dossiers existants pour préserver les commandes et les liens. L’introduction disponible a été raccordée aux neuf parties et aux deux parcours.

La provenance est conservée dans les [archives du projet](archives/README.md) et l’[état historique](archives/etat-2026-09-18.md). Le commit local perdu `ff0d73b` n’a pas été récupéré ; les exports actuels sont reconstruits à partir des fichiers disponibles.

## Avant et pendant la bêta

- Relire le rendu ZdS : sommaire, images, notes, tableaux et blocs de code. L’auteur a signalé un import sans images ; le guide fournit désormais deux ZIP distincts.
- Tester le parcours de tâches de travail dans un navigateur et la variante n8n dans son moteur.
- Réaliser les essais avec des assistants réels et les expériences sur la machine de l’auteur : GPU, interfaces et reprise des ateliers.
- Vérifier les variantes Windows et macOS concernées.
- Recueillir les retours de lecteurs sur les prérequis et l’orientation entre parcours.

Une première rédaction ou un contrôle automatique ne vaut pas validation de publication. Les rapports datés conservent leurs versions et leurs limites ; les nouvelles exécutions devront être distinguées des références existantes.
