# Exécutions de l’atelier MCP

[Rapport et limites](../../tutoriel/06-mcp-skills/VERIFICATION.md).

`executions.json` conserve les commandes, les erreurs d’outils attendues, les empreintes des données et celle de l’archive extraite. Les dix journaux numérotés sont les réponses réellement enregistrées par `client.py`, avec le SDK 2.2.0. `tests.txt` est la sortie réelle des dix tests en mémoire. Les messages de refus qui y figurent appartiennent aux cas de test attendus.

Aucun appel à un modèle, aucun accès à des tickets réels.
