# Crédits et sources

Textes et schémas originaux : Hugo Loiseau, CC BY-SA 4.0. Code des ateliers : GPL-3.0-only.

Les schémas sont produits par `outils/illustrer_agents.py`. Les sorties du banc et des tests sont des exécutions de scripts de démonstration, sans appel à un modèle. Les demandes de ces scripts, le document piégé, les contextes comparés et le CSV de coût sont des exemples fictifs. Les essais avec les assistants restent à réaliser sur les installations des lecteurs.

Les références techniques figurent dans les notes. La forme suit [Rédiger sur ZdS](https://zestedesavoir.com/tutoriels/249/rediger-sur-zds/) ; l’archive du tutoriel Vim sert de repère pédagogique, sans reprise de ses formulations.
