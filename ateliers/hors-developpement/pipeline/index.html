Préparer le point d’équipe

Une extraction, des contrôles, une relecture et un point interne à télécharger. Cette application n’appelle aucun modèle, n’envoie aucun message et ne confirme aucune inscription. Tout reste dans ce navigateur et dans les fichiers que vous téléchargez.

Commencez par charger l’exemple fictif ou coller votre extraction JSON.

1. Contrôler le lot reçu

Le format, les identifiants, la référence de chaque message et la présence exacte de son extrait sont contrôlés. La fidélité des valeurs extraites reste à vérifier dans les sources. Les champs de date et d’horaire restent à null pour ce lot.

2. Relire une version précise

L’accord porte sur ce point interne exact. Modifier l’extraction ou le point annule l’accord. Les messages nouveaux sont marqués « pris en compte » uniquement lorsque vous déclenchez le téléchargement du point ; leur inscription reste à examiner.

Sources consultables

Ouvrez les fichiers ci-dessous pour comparer les faits au texte complet. Ces copies sont intégrées à l’application à partir du dossier fourni, y compris la copie de M001. Un extrait réel peut accompagner une interprétation fausse.

3. Garder une trace, reprendre le travail

L’état contient les identifiants connus, les points exportés, les brouillons et le journal. À la reprise, aucun accord n’est conservé : contrôlez et relisez le brouillon. Rejouer le lot déjà exporté n’ajoute aucun rapport. Sans sauvegarde, fermer ou recharger la page perd l’état de la séance.

Le navigateur déclenche le téléchargement, mais ne nous dit pas si vous l’avez conservé. Si vous l’annulez, les identifiants sont tout de même marqués dans cette séance ; le point reste dans le fichier d’état. Ce fichier est inspectable et modifiable : il ne constitue ni un journal inviolable ni une protection pour une équipe entière.
